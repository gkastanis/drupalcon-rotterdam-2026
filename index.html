Summit day — George’s preference is the technical AI Dev Summit; Kostas can choose whichever summit fits him best.

George’s pick + alternative

George’s pick — AI Dev Summit

Technical AI track: agent architecture, guardrails, context, observability and developer workflows.

09:00 · Humans and AI Agents, One Contribution Loop — Nick Veenhof

Nick Veenhof on combining human review and AI agents in a persistent contribution loop, with guardrails and integrated review.

09:30 · Pluto: Infrastructure for AI-Native Development — Sam Zwaaij · Jordy Vleugel · Michael Schmid

Infrastructure and architecture for AI-native software development, from the coding workflow up.

10:00 · FlowDrop in Production — Shibin Das

Observable, asynchronous and cost-controlled agentic workflows for Drupal — especially relevant to long-running, production-grade agents.

10:30 · From Developer to Code Director — Martin Anderson-Clutz

How the developer role changes when AI generates more implementation and humans direct, review and integrate the work.

13:30 · Context as a Platform — Marcus Johansson

Marcus Johansson on treating context as reusable platform infrastructure rather than one-off prompt configuration.

14:00 · Guardrails and Control — Luca Lusso

Patterns for constraining AI behavior and retaining deterministic control around probabilistic systems.

15:30 · Operationalizing AI Safely in Enterprise Workflows — Jürgen Haas

Jürgen Haas on operational AI workflows without spreading custom code everywhere, with an enterprise/ECA perspective.

16:00 · Breakout topic tables — All attendees / table facilitators

Best networking block. Prioritize tables around agents, evals, guardrails, context and production AI.
